          <summary>BS.1770-5 Core Equations</summary>


          <p>Filter stages (K-weighting):</p>

          <p>\[

          H_1(z) = \frac{b_0 + b_1 z^{-1} + b_2 z^{-2}}

                       {1 + a_1 z^{-1} + a_2 z^{-2}},\quad

          (b_0,b_1,b_2)=(1.5351,-2.6917,1.1984),\ 

          (a_1,a_2)=(-1.6907,0.7325)

          \]</p>

          <p>\[

          H_2(z) = \frac{1 - 2z^{-1} + z^{-2}}

                       {1 - 1.9900 z^{-1} + 0.9901 z^{-2}}

          \]</p>


          <p>Block energy per channel \(i\), 400&nbsp;ms blocks:</p>

          <p>\[

          z_i = \frac{1}{N}\sum_{n=0}^{N-1} y_i^2[n]

          \]</p>


          <p>Channel-weighted loudness for one block:</p>

          <p>\[

          L_K = -0.691 + 10\log_{10}\Bigl(\sum_i G_i z_i\Bigr)

          \]</p>


          <p>Two-stage gating:</p>

          <p>\[

          \Gamma_a = -70\ \mathrm{LKFS},\qquad

          \Gamma_r = L_{\text{prelim}} - 10\ \mathrm{LU}

          \]</p>


          <p>Integrated loudness over gated blocks \(J_g\):</p>

          <p>\[

          L_{\text{integrated}}

          =

          -0.691 + 10\log_{10}\!\left(

            \frac{1}{|J_g|}

            \sum_{j \in J_g}\sum_i G_i z_{ij}

          \right)

          \]</p>


          <p>Loudness Range (LRA), 3&nbsp;s windows, 1&nbsp;s hop:</p>

          <p>\[

          \mathrm{LRA} = P_{95}(l_j) - P_{10}(l_j)

          \]</p>

        </details>

          <summary>Zwicker Loudness, Crest Factor &amp; Peak Density</summary>


          <p>Approximate Zwicker loudness in sones uses specific loudness over Bark bands:</p>

          <p>\[

          N = \int_0^{24} N'(z)\,dz

          \approx

          \sum_{b=1}^{B} N'(z_b)\,\Delta z,

          \quad \Delta z \approx 1\ \text{Bark}.

          \]</p>


          <p>We approximate band levels \(L_b\) (dB) as phons at each Bark band and use:</p>

          <p>\[

          N'(z_b) \approx

          \begin{cases}

          \left(\dfrac{L_b}{40}\right)^{2.6}, & L_b < 40\ \mathrm{phon}\\[4pt]

          2^{\frac{L_b-40}{10}}, & L_b \ge 40\ \mathrm{phon}

          \end{cases}

          \]</p>

          <p>so that a 40&nbsp;phon tone is ≈1&nbsp;sone when summed across bands.</p>


          <p>For a time region \([t_0,t_1]\), band levels are averaged over frames:</p>

          <p>\[

          \bar L_b = \frac{1}{K}\sum_{k\in[t_0,t_1]} L_b(k),

          \quad

          N \approx \sum_b N'(\bar L_b).

          \]</p>


          <p>Crest factor (in dB) for a region is:</p>

          <p>\[

          C_\mathrm{dB} = 20\log_{10}\left(\frac{x_\mathrm{peak}}{x_\mathrm{rms}}\right),

          \quad

          x_\mathrm{rms} = \sqrt{\frac{1}{N}\sum_{n}x^2[n]}.

          \]</p>


          <p>Peak density (peaks / second) with threshold \(T\) (e.g. −18 dBFS) is:</p>

          <p>\[

          \rho_\mathrm{peaks}

          = \frac{N_\mathrm{peaks}}{T_\mathrm{region}},

          \quad

          T_\mathrm{region} = t_1 - t_0,

          \]</p>

          <p>where \(N_\mathrm{peaks}\) counts local maxima whose amplitude exceeds \(T\).</p>

        </details>

        <div class="section-title">Persistent Masking Map (MPEG-1 Model 1) — Main</div>

        <details class="math-block math-bg-mp3" close>

          <summary>MPEG-1 Model 1 (Masking)</summary>

          

          <!-- explanations -->

          

          <p>FFT and power spectrum:</p>

          <p>\[

          X(k) = \mathrm{FFT}\{x[n]\},\qquad

          P(k) = |X(k)|^2

          \]</p>


          <p>Bark mapping:</p>

          <p>\[

          z(f) =

          13\arctan(0.00076 f) +

          3.5\arctan\!\left(\left(\frac{f}{7500}\right)^2\right)

          \]</p>


          <p>Tonal maskers:</p>

          <p>\[

          P_{\mathrm{tonal}}(k_m)

          = P(k_m-1) + P(k_m) + P(k_m+1)

          \]</p>


          <p>Noise maskers per Bark band \(b\):</p>

          <p>\[

          P_{\mathrm{noise}}(b)

          = \sum_{k \in b}' P(k)

          \]</p>


          <p>Spreading function:</p>

          <p>\[

          \mathrm{SF}(\Delta z) =

          15.81 + 7.5(\Delta z + 0.474)

          - 17.5 \sqrt{1 + (\Delta z + 0.474)^2}

          \]</p>


          <p>Individual masking thresholds (\(L_m\) in dB SPL):</p>

          <p>\[

          LT_i(z) = L_m + \mathrm{SF}(z - z_m) - \mathrm{NMT/TMN}

          \]</p>

          <p>\[

          \mathrm{TMN} = 14.5\ \mathrm{dB}\quad

          \text{(tonal)},\qquad

          \mathrm{NMT} \approx 3\text{–}5\ \mathrm{dB}\quad

          \text{(noise)}

          \]</p>


          <p>Global masking threshold:</p>

          <p>\[

          LT_{\mathrm{global}}(z)

          =

          10\log_{10}\!\left(

            10^{ATH(z)/10}

            +

            \sum_{i\in\mathrm{tonal}} 10^{LT_i(z)/10}

            +

            \sum_{i\in\mathrm{noise}} 10^{LT_i(z)/10}

          \right)

          \]</p>


          <p>Masking margin per bin:</p>

          <p>\[

          \Delta(k) =

          10\log_{10} P(k) - LT_{\mathrm{global}}(z(k))

          \]</p>

        </details>


        <!-- Persistent masking explanation -->

        <details class="math-block math-bg-masking" close>

          <summary>Persistent Masking (Occupancy)</summary>


          <p>Band-time margin and binary mask:</p>

          <p>\[

          \Delta(b,t)

          = 10\log_{10} P(b,t) - LT_{\mathrm{global}}(b,t)

          \]</p>

          <p>\[

          M(b,t) =

          \begin{cases}

          1, & \Delta(b,t) < 0 \\

          0, & \Delta(b,t) \ge 0

          \end{cases}

          \]</p>


          <p>Sliding-window occupancy over \(W\) frames:</p>

          <p>\[

          R(b,t)

          = \frac{1}{W}

            \sum_{k = t - W/2}^{t + W/2}

            M(b,k)

          \]</p>


          <p>Persistent mask (occupancy ≥ \(\alpha\)):</p>

          <p>\[

          M_{\mathrm{persist}}(b,t) =

          \begin{cases}

          1, & R(b,t) \ge \alpha \\

          0, & R(b,t) < \alpha

          \end{cases}

          \]</p>


          <p>Energy gate (e.g. \(L_{\min} = -60\ \mathrm{dBFS}\)):</p>

          <p>\[

          A(b,t) =

          \begin{cases}

          1, & L(b,t) > L_{\min} \\

          0, & \text{otherwise}

          \end{cases}

          \]</p>


          <p>Final persistent mask:</p>

          <p>\[

          M_{\mathrm{persist}}(b,t)

          \leftarrow

          M_{\mathrm{persist}}(b,t)\,A(b,t)

          \]</p>

        </details>

/**

 * Format seconds as "mm:ss".

 * @param {number} sec - time in seconds

 * @returns {string} formatted time

 */

function formatTime(sec) {

  if (!isFinite(sec) || sec < 0) sec = 0;

  const m = Math.floor(sec / 60);

  const s = Math.floor(sec % 60);

  return `${String(m).padStart(2,'0')}:${String(s).padStart(2,'0')}`;

}

 * @param {number} currentSec

}


/**

 * Clamp a value between lo and hi.

  return Math.max(lo, Math.min(hi, v));

/**

 * Apply K-weighting prefilters offline using OfflineAudioContext.

 * Resamples to 48 kHz and runs two IIR filters in series.

 * @param {AudioBuffer} buffer - original decoded audio

 * @returns {Promise<AudioBuffer>} - filtered buffer

 */

async function kWeightOffline(buffer) {

  const targetSR = 48000;                            // target sample rate for analysis

  const length48 = Math.ceil(buffer.duration * targetSR); // approximate new length

  const offline = new OfflineAudioContext(buffer.numberOfChannels, length48, targetSR);


  const src = offline.createBufferSource();

  src.buffer = buffer;


  const pref1 = offline.createIIRFilter(K_PREFILTER1_FF, K_PREFILTER1_FB);

  const pref2 = offline.createIIRFilter(K_PREFILTER2_FF, K_PREFILTER2_FB);


  // src -> H1 -> H2 -> destination

  src.connect(pref1).connect(pref2).connect(offline.destination);


  src.start(0);

  return offline.startRendering(); // renders entire buffer and resolves with new AudioBuffer

}

/**

 * Analyze loudness on a K-weighted buffer with BS.1770 style gating.

 * Returns integrated LUFS, LRA, min/max local, plus times of blocks.

 *

 * @param {AudioBuffer} buffer

 * @param {number[]} [channelWeights=null] optional per-channel weights

 */

function analyzeLoudness(buffer, channelWeights = null) {

  const sr  = buffer.sampleRate;

  const len = buffer.length;

  const ch  = buffer.numberOfChannels;


  // Block / hop sizes: 400 ms blocks, 100 ms hop (BS.1770)

  const blockSize = Math.round(sr * 0.400);

  const hopSize   = Math.round(sr * 0.100);


  // Channel weights Gi

  const g = channelWeights && channelWeights.length === ch

    ? channelWeights.slice()

    : Array(ch).fill(1.0);


  // Pre-fetch float channel arrays

  const data = Array.from({length: ch}, (_, i) => buffer.getChannelData(i));


  // Convert mean-square to LKFS (Eq: -0.691 + 10 log10( sum(G_i^2 z_i) ) )

  const msToLUFS = (ms) => ms <= 0 ? -Infinity : -0.691 + 10 * Math.log10(ms);


  // Simple mean helper

  const mean = (arr) => arr.length ? arr.reduce((a,b)=>a+b,0) / arr.length : NaN;


  // Percentile helper (0-100)

  const percentile = (arr, p) => {

    if (!arr.length) return NaN;

    const a = arr.slice().sort((x,y)=>x-y);

    const idx = (p/100) * (a.length - 1);

    const lo = Math.floor(idx), hi = Math.ceil(idx);

    return lo === hi ? a[lo] : a[lo] + (a[hi]-a[lo])*(idx-lo);

  };


  /**

   * Compute block mean-square for one time interval across channels.

   * @param {number} start - sample index

   * @param {number} size  - block size in samples

   */

  const blockMS = (start, size) => {

    const end = Math.min(len, start + size);

    let sum = 0;

    for (let c = 0; c < ch; c++) {

      if (g[c] === 0) continue;

      const d = data[c];

      let s = 0;

      for (let i = start; i < end; i++) s += d[i] * d[i];

      const ms_c = s / (end - start);

      sum += (g[c] * g[c]) * ms_c;

    }

    return sum;

  };


  // Block scanning in time: store mean-square and LKFS per block

  const blocksMS = [];

  const blocksLUFS = [];

  const blocksTimes = [];

  for (let start = 0; start + blockSize <= len; start += hopSize) {

    const ms = blockMS(start, blockSize);

    blocksMS.push(ms);

    const l = msToLUFS(ms);

    blocksLUFS.push(l);

    const center = start + blockSize * 0.5;

    const timeSec = center / sr;

    blocksTimes.push(timeSec);

  }

  const totalBlocks = blocksMS.length;


  // Absolute gate: discard blocks below -70 LKFS

  const absIdx = [];

  for (let i = 0; i < totalBlocks; i++) if (blocksLUFS[i] > -70) absIdx.push(i);


  // If no blocks above threshold, return -∞

  if (!absIdx.length) {

    return {

      integratedLUFS: -Infinity,

      keptBlocks: 0,

      totalBlocks,

      lra: NaN,

      minLocalLUFS: null,

      maxLocalLUFS: null,

      blocksLUFS,

      blocksTimes

    };

  }


  // Preliminary loudness using only blocks above absolute gate

  const prelimMS = mean(absIdx.map(i => blocksMS[i]));

  const prelimLUFS = msToLUFS(prelimMS);


  // Relative gate: 10 LU below preliminary

  const rel10 = prelimLUFS - 10.0;

  const keptIdx = [];

  for (let k = 0; k < absIdx.length; k++) {

    const i = absIdx[k];

    if (blocksLUFS[i] >= rel10) keptIdx.push(i);

  }


  // If nothing passes relative gate, also -∞

  if (!keptIdx.length) {

    return {

      integratedLUFS: -Infinity,

      keptBlocks: 0,

      totalBlocks,

      lra: NaN,

      minLocalLUFS: null,

      maxLocalLUFS: null,

      blocksLUFS,

      blocksTimes

    };

  }


  // Integrated loudness over kept blocks

  const finalMS = mean(keptIdx.map(i => blocksMS[i]));

  const integratedLUFS = msToLUFS(finalMS);


  // LRA: 3s windows with 1s hop across entire piece (BS.1770 style)

  const stSize = Math.round(sr * 3.0);

  const stHop  = Math.round(sr * 1.0);

  const stVals = [];

  for (let start = 0; start + stSize <= len; start += stHop) {

    const ms = blockMS(start, stSize);

    const l  = msToLUFS(ms);

    stVals.push(l);

  }

  // LRA gating: exclude values more than 20 LU below integrated

  const lraGate = Math.max(-70, integratedLUFS - 20);

  const stGated = stVals.filter(l => isFinite(l) && l >= lraGate);

  const lra = stGated.length >= 10 ? (percentile(stGated, 95) - percentile(stGated, 10)) : NaN;


  // Min/max local loudness among kept blocks

  let minLocalLUFS = null;

  let maxLocalLUFS = null;

  if (keptIdx.length) {

    const keptLUFS = keptIdx.map(i => blocksLUFS[i]).filter(v => isFinite(v));

    if (keptLUFS.length) {

      minLocalLUFS = Math.min(...keptLUFS);

      maxLocalLUFS = Math.max(...keptLUFS);

    }

  }


  return {

    integratedLUFS,

    keptBlocks: keptIdx.length,

    totalBlocks,

    lra,

    minLocalLUFS,

    maxLocalLUFS,

    blocksLUFS,

    blocksTimes

  };

}

 * @param {Object} opts

 * @param {boolean} opts.normalized - whether to normalize to platform target

 * @param {number} opts.offsetSec - where to start playback (seconds)

 */

function startPlayback({ normalized, offsetSec = 0 }) {

  if (!audioCtx || !decodedBuffer || !lastAnalysis) {

    statusElement.textContent = "Nothing to play yet. Analyze a file first.";

    return;

  }


  if (audioCtx.state === "suspended") {

    audioCtx.resume();

  }


  // Make sure any previous playback is stopped

  stopPlayback();


  const duration = decodedBuffer.duration;

  const startOffset = Math.max(0, Math.min(duration, offsetSec));


  // New buffer source

  currentSource = audioCtx.createBufferSource();

  currentSource.buffer = decodedBuffer;


  // Determine platform loudness target based on dropdown

  const platform = platformSelect.value;

  const targetLUFS = ({

    spotify: -14,

    youtube: -14,

    apple:   -16,

    tidal:   -14

  })[platform] ?? -14;


  // Gain node for loudness normalization

  const gainNode = audioCtx.createGain();

  if (normalized && isFinite(lastAnalysis.integratedLUFS)) {

    const diffDb = targetLUFS - lastAnalysis.integratedLUFS; // desired - current

    const lin = Math.pow(10, diffDb / 20);                    // convert dB to linear

    gainNode.gain.value = lin;

    statusElement.textContent = `Playing normalized to ${targetLUFS} LUFS for ${platformSelect.options[platformSelect.selectedIndex].text}.`;

  } else {

    gainNode.gain.value = 1.0;

    statusElement.textContent = "Playing original (no loudness normalization in the chain).";

  }


  // Analyser node for peak/VU meters

  meterAnalyser = audioCtx.createAnalyser();

  meterAnalyser.fftSize = 2048;

  meterAnalyser.smoothingTimeConstant = 0.8;

  meterTimeData = new Float32Array(meterAnalyser.fftSize);


  // Create EQ filters

  createEQNodes(audioCtx);


  // Connect graph: source -> low -> mid -> high -> gain -> analyser -> destination

    .connect(eqNodes.low)

    .connect(eqNodes.mid)

    .connect(eqNodes.high)

    .connect(gainNode)

    .connect(meterAnalyser)

    .connect(audioCtx.destination);

  playbackStartTime = audioCtx.currentTime;

    stopPlayback();

    statusElement.textContent = "Playback finished.";

  };

  currentSource.start(0, startOffset);

/**

 * Meter update loop with requestAnimationFrame.

 * Computes peak, RMS and VU from analyser time-domain data.

 */

function startMeterLoop() {

    if (!meterAnalyser) {

      meterRafId = null;

      return;

    }


    // Read current time-domain signal

    meterAnalyser.getFloatTimeDomainData(meterTimeData);


    let maxAbs = 0;

    let sumSq = 0;

    for (let i = 0; i < meterTimeData.length; i++) {

      const v = meterTimeData[i];

      const av = Math.abs(v);

      if (av > maxAbs) maxAbs = av;

      sumSq += v * v;

    }


    const rms = Math.sqrt(sumSq / meterTimeData.length) || 1e-12;

    const dBPeak = 20 * Math.log10(maxAbs || 1e-12);

    const dBRms  = 20 * Math.log10(rms);


    const vu = dBRms + 18; // 0 VU corresponds to -18 dBFS


    meterPeakText.textContent = `${dBPeak.toFixed(1)} dB`;

    meterVuText.textContent   = `${vu.toFixed(1)} VU`;


    // Normalize bars to fixed dB ranges

    const peakNorm = Math.max(0, Math.min(1, (dBPeak + 60) / 60)); // -60..0 dB → 0..1

    const vuNorm   = Math.max(0, Math.min(1, (vu + 20) / 20));     // -20..0 VU → 0..1

    barPeak.style.width = `${peakNorm * 100}%`;

    barVu.style.width   = `${vuNorm * 100}%`;


    // Update seek bar and playhead

    if (currentSource && audioCtx) {

      const tNow = audioCtx.currentTime;

      const pos = Math.min(trackDurationSec, playbackOffsetSec + (tNow - playbackStartTime));

      seekBar.value = pos;

      updateSeekLabel(pos);

      playheadSec = pos;

      drawLoudnessCurve();

    }


    meterRafId = requestAnimationFrame(loop);

  }

  meterRafId = requestAnimationFrame(loop);

}

/**

 * In-place radix-2 FFT, re/im arrays length must be power of 2.

 */

function fftRadix2(re, im) {

  const n = re.length;

  if ((n & (n - 1)) !== 0) {

    throw new Error("FFT size must be a power of 2.");

  }

  // Bit-reversal permutation

  let j = 0;

  for (let i = 0; i < n; i++) {

    if (i < j) {

      [re[i], re[j]] = [re[j], re[i]];

      [im[i], im[j]] = [im[j], im[i]];

    }

    let m = n >> 1;

    while (m >= 1 && j >= m) {

      j -= m;

      m >>= 1;

    }

    j += m;

  }

  // Cooley–Tukey butterfly stages

  for (let size = 2; size <= n; size <<= 1) {

    const half = size >> 1;

    const theta = -2 * Math.PI / size;

    const wpr = Math.cos(theta);

    const wpi = Math.sin(theta);

    for (let i = 0; i < n; i += size) {

      let wr = 1, wi = 0;

      for (let k = 0; k < half; k++) {

        const i0 = i + k;

        const i1 = i + k + half;

        const tr = wr * re[i1] - wi * im[i1];

        const ti = wr * im[i1] + wi * re[i1];

        re[i1] = re[i0] - tr;

        im[i1] = im[i0] - ti;

        re[i0] += tr;

        im[i0] += ti;

        const tmpWr = wr * wpr - wi * wpi;

        wi = wr * wpi + wi * wpr;

        wr = tmpWr;

      }

    }

  }

}


/**

 * Convert frequency in Hz to Bark scale.

 */

function hzToBark(f) {

  return 13 * Math.atan(0.00076 * f) +

         3.5 * Math.atan(Math.pow(f / 7500, 2));

}


/**

 * Approximate threshold in quiet (ATH) in dB SPL at frequency fHz.

 */

function athDb(fHz) {

  const f = fHz / 1000;

  if (f <= 0) return 100;

  const term1 = 3.64 * Math.pow(f, -0.8);

  const term2 = -6.5 * Math.exp(-0.6 * Math.pow(f - 3.3, 2));

  const term3 = 0.001 * Math.pow(f, 4);

  return term1 + term2 + term3;

}

/**

 * Compute MPEG-1 Model 1-style masking for mono mix of buffer.

 * Returns Bark-band levels, thresholds, instantaneous mask, margins, etc.

 *  - numFrames: number of time frames

 *  - numBands: Bark bands

 *  - instMask[b][t]: 1 if masked in band b at time t, else 0

 *  - margin[b][t]: L(b,t) - LT_global(b,t) in dB

 *  - levels[b][t], thresholds[b][t]

 *  - frameHopSec: time spacing between frames

 *  - bandFreqCenter[b]: center frequency of band b (Hz)

 */

function computeMp3Masking(buffer) {

  const sr = buffer.sampleRate;

  const ch = buffer.numberOfChannels;

  const len = buffer.length;


  // Mono downmix: average across channels

  const mono = new Float32Array(len);

  for (let c = 0; c < ch; c++) {

    const d = buffer.getChannelData(c);

    for (let i = 0; i < len; i++) {

      mono[i] += d[i] / ch;

    }

  }


  const N = 512;                  // FFT size

  const overlapFraction = 1 / 16; // 1/16 overlap => hop = N - N/16

  const hop = N - Math.floor(N * overlapFraction); // 512 - 32 = 480

  const numFrames = Math.max(0, 1 + Math.floor((len - N) / hop));

  if (numFrames <= 0) {

    return {

      numFrames: 0,

      numBands: 0,

      instMask: [],

      margin: [],

      levels: [],

      thresholds: [],

      frameHopSec: hop / sr,

      bandFreqCenter: []

    };

  }


  const frameHopSec = hop / sr;   // time between frames


  // Hann window for each frame

  const win = new Float32Array(N);

  for (let n = 0; n < N; n++) {

    win[n] = 0.5 * (1 - Math.cos(2 * Math.PI * n / (N - 1)));

  }


  const halfN = N / 2;

  const re = new Float32Array(N);

  const im = new Float32Array(N);

  const P = new Float32Array(halfN + 1);    // power spectrum

  const Lbin = new Float32Array(halfN + 1); // bin level dB


  // Precompute Bark and frequency per bin

  const bark = new Float32Array(halfN + 1);

  const freq = new Float32Array(halfN + 1);

  let maxBark = 0;

  for (let k = 0; k <= halfN; k++) {

    const f = (k * sr) / N;

    freq[k] = f;

    const z = hzToBark(f);

    bark[k] = z;

    if (z > maxBark) maxBark = z;

  }


  // Integer Bark bands [0..ceil(maxBark)-1]

  const numBands = Math.max(1, Math.ceil(maxBark));


  // Map each bin to one Bark band

  const bandBinIndices = Array.from({ length: numBands }, () => []);

  for (let k = 0; k <= halfN; k++) {

    let b = Math.floor(bark[k]);

    if (b < 0) b = 0;

    if (b >= numBands) b = numBands - 1;

    bandBinIndices[b].push(k);

  }


  // Compute center frequency for each band

  const bandFreqCenter = new Float32Array(numBands);

  for (let b = 0; b < numBands; b++) {

    const bins = bandBinIndices[b];

    if (!bins.length) {

      bandFreqCenter[b] = 0;

      continue;

    }

    let sumF = 0;

    let count = 0;

    for (let i = 0; i < bins.length; i++) {

      const k = bins[i];

      sumF += freq[k];

      count++;

    }

    bandFreqCenter[b] = count ? (sumF / count) : 0;

  }


  const eps = 1e-12;


  // Allocate 2D arrays (band x frame) for levels, thresholds, masks, margins

  const framesL   = Array.from({ length: numBands }, () => new Array(numFrames).fill(-120));

  const framesLT  = Array.from({ length: numBands }, () => new Array(numFrames).fill(-120));

  const framesM   = Array.from({ length: numBands }, () => new Array(numFrames).fill(0));

  const framesDel = Array.from({ length: numBands }, () => new Array(numFrames).fill(0));


  // TMN/NMT as in MPEG model (tonal vs noise)

  const TMN = 14.5;

  const NMT = 5.0;


  // Spreading function SF(Δz)

  function spreadingFunction(dz) {

    const v = dz + 0.474;

    return 15.81 + 7.5 * v - 17.5 * Math.sqrt(1 + v * v);

  }


  // Loop over frames in time

  for (let frame = 0; frame < numFrames; frame++) {

    const start = frame * hop;


    // Windowed frame into re/im

    for (let n = 0; n < N; n++) {

      const idx = start + n;

      const x = idx < len ? mono[idx] : 0;

      re[n] = x * win[n];

      im[n] = 0;

    }


    // Perform FFT

    fftRadix2(re, im);


    // Compute power and dB level for positive frequencies

    for (let k = 0; k <= halfN; k++) {

      const pr = re[k];

      const pi = im[k];

      const mag2 = pr * pr + pi * pi;

      P[k] = mag2;

      Lbin[k] = 10 * Math.log10(mag2 + eps);

    }


    // Detect tonal maskers

    const usedInTonal = new Array(halfN + 1).fill(false);

    const tonalMaskers = [];

    for (let k = 2; k <= halfN - 2; k++) {

      const Lk = Lbin[k];

      const Lkm1 = Lbin[k - 1];

      const Lkp1 = Lbin[k + 1];


      // Local maximum and 7 dB above neighbors

      if (

        Lk > Lkm1 && Lk > Lkp1 &&

        Lk >= Lkm1 + 7 && Lk >= Lkp1 + 7

      ) {

        // Combine three bins to form tonal masker power

        const Ptonal = (P[k - 1] || 0) + (P[k] || 0) + (P[k + 1] || 0);

        const Lm = 10 * Math.log10(Ptonal + eps);

        const zm = bark[k];

        tonalMaskers.push({ L: Lm, z: zm });

        usedInTonal[k - 1] = true;

        usedInTonal[k] = true;

        usedInTonal[k + 1] = true;

      }

    }


    // Noise maskers per Bark band (exclude tonal bins)

    const noiseMaskers = [];

    for (let b = 0; b < numBands; b++) {

      const bins = bandBinIndices[b];

      if (!bins.length) continue;


      let sumP = 0;

      let sumPz = 0;

      for (let i = 0; i < bins.length; i++) {

        const k = bins[i];

        if (usedInTonal[k]) continue;

        const pk = P[k];

        sumP += pk;

        sumPz += pk * bark[k];

      }

      if (sumP > 0) {

        const Lm = 10 * Math.log10(sumP + eps);

        const zm = sumPz / sumP;

        noiseMaskers.push({ L: Lm, z: zm });

      }

    }


    // Compute band levels L(b,t)

    for (let b = 0; b < numBands; b++) {

      const bins = bandBinIndices[b];

      let sumPb = 0;

      for (let i = 0; i < bins.length; i++) {

        const k = bins[i];

        sumPb += P[k];

      }

      const Lb = sumPb > 0 ? 10 * Math.log10(sumPb + eps) : -120;

      framesL[b][frame] = Lb;

    }


    // Build global masking threshold per band + margin

    for (let b = 0; b < numBands; b++) {

      const z_b = b + 0.5;                         // approximate Bark center

      const fCenter = bandFreqCenter[b] || 1000;   // fallback center frequency

      let sumPower = 0;


      // Add threshold in quiet (ATH)

      const ATH = athDb(fCenter);

      sumPower += Math.pow(10, ATH / 10);


      // Add tonal masker contributions

      for (let m = 0; m < tonalMaskers.length; m++) {

        const mk = tonalMaskers[m];

        const dz = z_b - mk.z;

        const SF = spreadingFunction(dz);

        const LT_i = mk.L + SF - TMN;

        sumPower += Math.pow(10, LT_i / 10);

      }


      // Add noise masker contributions

      for (let m = 0; m < noiseMaskers.length; m++) {

        const mk = noiseMaskers[m];

        const dz = z_b - mk.z;

        const SF = spreadingFunction(dz);

        const LT_i = mk.L + SF - NMT;

        sumPower += Math.pow(10, LT_i / 10);

      }


      const LT_global = 10 * Math.log10(sumPower + eps);

      const Lb = framesL[b][frame];

      const delta = Lb - LT_global;


      framesLT[b][frame]  = LT_global;      // global threshold

      framesDel[b][frame] = delta;          // masking margin

      framesM[b][frame]   = delta < 0 ? 1 : 0; // instantaneous mask bit

    }

  }


  return {

    numFrames,

    numBands,

    instMask: framesM,

    margin: framesDel,

    levels: framesL,

    thresholds: framesLT,

    frameHopSec,

    bandFreqCenter

  };

}

/**

 * Build persistent masking mask from instantaneous mask + levels.

 * Occupancy R(b,t) over window W is thresholded by alpha.

 *

 * @param {Object} base - mp3LastRes-like object

 * @param {number} alpha - occupancy threshold (0..1)

 * @param {number} W - window length in frames (odd)

 * @param {number} Lmin - minimum level in dBFS for energy gate

 */

function buildPersistentMask(base, alpha, W, Lmin) {

  const { numBands, numFrames, instMask, levels } = base;

  const halfW = Math.floor(W / 2);

  const mask = Array.from({ length: numBands }, () => new Array(numFrames).fill(false));


  for (let b = 0; b < numBands; b++) {

    for (let t = 0; t < numFrames; t++) {

      let occ = 0;

      let count = 0;

      for (let k = t - halfW; k <= t + halfW; k++) {

        if (k < 0 || k >= numFrames) continue;

        occ += instMask[b][k];

        count++;

      }

      const R = count ? (occ / count) : 0;

      const Lbt = levels[b][t];


      // Persist if occupancy≥alpha and band level > Lmin

      if (R >= alpha && Lbt > Lmin) {

        mask[b][t] = true;

      }

    }

  }

  return { mask, alpha, W, Lmin };

}

/**

 * Draw axes overlays on heatmaps: time along x, frequency labels on y.

 */

function drawAxes(ctx, canvas, numFrames, numBands, frameHopSec, bandFreqCenter) {

  const w = canvas.width;

  const h = canvas.height;

  const cellW = w / numFrames;

  const cellH = h / numBands;


  ctx.fillStyle = "#9ca3af";

  ctx.font = "10px system-ui";

  ctx.textBaseline = "top";

  ctx.textAlign = "center";


  // Time axis ticks: 1s or 5s depending on length

  const totalTime = numFrames * frameHopSec;

  const tickStep = totalTime > 60 ? 5 : 1;

  for (let t = 0; t < numFrames; t++) {

    const timeSec = t * frameHopSec;

    if (Math.abs((timeSec / tickStep) - Math.round(timeSec / tickStep)) < 0.01) {

      const x = t * cellW;

      ctx.fillText(`${Math.round(timeSec)}s`, x, 2);

    }

  }


  // Frequency labels on right side

  ctx.textAlign = "right";

  ctx.textBaseline = "middle";


  const labelCount = 8;

  for (let i = 0; i < labelCount; i++) {

    const b = Math.round(i * (numBands - 1) / (labelCount - 1));

    const f = bandFreqCenter[b];

    if (!isFinite(f) || f <= 0) continue;

    const y = h - (b + 0.5) * cellH;

    const label = f >= 1000 ? `${(f/1000).toFixed(1)}k` : `${Math.round(f)}`;

    ctx.fillText(label + " Hz", w - 4, y);

  }

}


/**

 * Draw persistent masking heatmap for a result object (base).

 */

function drawMp3MaskingHeatmap(base, canvas, ctx) {

  clearMp3Heatmap(canvas, ctx);

  const { numFrames, numBands, persistMask, frameHopSec, bandFreqCenter } = base;

  if (!numFrames || !numBands || !persistMask) return;


  const w = canvas.width;

  const h = canvas.height;

  const cellW = w / numFrames;

  const cellH = h / numBands;


  ctx.fillStyle = "#020617";

  ctx.fillRect(0, 0, w, h);


  // Draw red blocks where persistent mask = true

  for (let b = 0; b < numBands; b++) {

    const y = h - (b + 1) * cellH;

    for (let t = 0; t < numFrames; t++) {

      if (!persistMask[b][t]) continue;

      const x = t * cellW;

      ctx.fillStyle = "#ef4444";

      ctx.fillRect(x, y, cellW + 0.5, cellH + 0.5);

    }

  }


  drawAxes(ctx, canvas, numFrames, numBands, frameHopSec, bandFreqCenter);

}


/**

 * Map margin Δ(b,t) in [−20,0] to a red HSL color.

 */

function deltaToColor(deltaDb) {

  if (!isFinite(deltaDb)) return "#020617";

  if (deltaDb >= 0) return "#020617"; // non-masked: dark

  const clipped = Math.max(-20, Math.min(0, deltaDb));

  const a = Math.abs(clipped) / 20;

  const light = 20 + 40 * a; // brightness 20→60 as margin gets more negative

  return `hsl(0,80%,${light}%)`;

}


/**

 * Draw masking margin heatmap Δ(b,t) using red intensity for negative margins.

 */

function drawMp3MarginHeatmap(base, canvas, ctx) {

  clearMp3MarginHeatmap(canvas, ctx);

  const { numFrames, numBands, margin, frameHopSec, bandFreqCenter } = base;

  if (!numFrames || !numBands) return;


  const w = canvas.width;

  const h = canvas.height;

  const cellW = w / numFrames;

  const cellH = h / numBands;


  ctx.fillStyle = "#020617";

  ctx.fillRect(0, 0, w, h);


  for (let b = 0; b < numBands; b++) {

    const y = h - (b + 1) * cellH;

    const row = margin[b];

    for (let t = 0; t < numFrames; t++) {

      const delta = row[t];

      const x = t * cellW;

      ctx.fillStyle = deltaToColor(delta);

      ctx.fillRect(x, y, cellW + 0.5, cellH + 0.5);

    }

  }


  drawAxes(ctx, canvas, numFrames, numBands, frameHopSec, bandFreqCenter);

}

function drawLoudnessCurve() {

  loudnessCanvas.height = h;

  ctx.fillRect(0, 0, w, h);

  const padR = 10;

  const padT = 10;

  const padB = 20;


  // Axes base lines

  ctx.strokeStyle = "#9ca3af";

  ctx.lineWidth = 1;

  ctx.beginPath();

  ctx.moveTo(padL, padT);

  ctx.lineTo(padL, h - padB);

  ctx.lineTo(w - padR, h - padB);

  ctx.stroke();

  if (!loudnessCurve || !loudnessCurve.times.length) {

    ctx.fillStyle = "#6b7280";

    ctx.font = "12px system-ui";

    ctx.fillText("No loudness blocks yet. Analyze a file first.", padL + 10, (h - padB + padT)/2);

    return;

  }


  const times = loudnessCurve.times;

  const values = loudnessCurve.values;

  const tMax = trackDurationSec || times[times.length - 1] || 1.0;

  let lMin = loudnessCurve.minL;

  let lMax = loudnessCurve.maxL;

  if (!isFinite(lMin) || !isFinite(lMax) || lMin === lMax) {

    lMin = -70;

    lMax = -10;

  }


  const plotW = w - padL - padR;

  const plotH = h - padT - padB;


  const timeToX = (t) => padL + (clamp(t, 0, tMax) / tMax) * plotW;

  const valToY  = (L) => {

    const v = clamp(L, lMin, lMax);

    const norm = (lMax - v) / (lMax - lMin);

    return padT + norm * plotH;

  };


  // Horizontal loudness grid lines (with LUFS labels)

  ctx.strokeStyle = "#e5e7eb";

  ctx.lineWidth = 1;

  ctx.font = "10px system-ui";

  ctx.fillStyle = "#9ca3af";

  for (let i = 0; i <= gridSteps; i++) {

    const frac = i / gridSteps;

    const L = lMin + (1 - frac) * (lMax - lMin);

    const y = valToY(L);

    ctx.beginPath();

    ctx.moveTo(padL, y);

    ctx.lineTo(w - padR, y);

    ctx.stroke();

    ctx.fillText(`${L.toFixed(1)} LUFS`, 2, y - 3);

  }


  // Vertical time grid lines at second intervals

  const tStep = tMax > 60 ? 10 : (tMax > 30 ? 5 : 1);

  ctx.textAlign = "center";

  for (let t = 0; t <= tMax; t += tStep) {

    const x = timeToX(t);

    ctx.beginPath();

    ctx.moveTo(x, padT);

    ctx.lineTo(x, h - padB);

    ctx.stroke();

    ctx.fillText(`${Math.round(t)}s`, x, h - padB + 4);

  }

  ctx.textAlign = "left";


  // Main loudness curve (solid blue)

  ctx.strokeStyle = "#1d4ed8";

  ctx.lineWidth = 1.5;

  ctx.beginPath();

  for (let i = 0; i < times.length; i++) {

    const x = timeToX(times[i]);

    const y = valToY(values[i]);

    if (i === 0) ctx.moveTo(x, y);

    else ctx.lineTo(x, y);

  }

  ctx.stroke();


  // Reference loudness curve overlay (if available) - dashed purple

  if (loudnessCurveRef && loudnessCurveRef.times && loudnessCurveRef.times.length) {

    ctx.save();

    ctx.strokeStyle = "#9333ea";

    ctx.lineWidth = 1.2;

    ctx.setLineDash([4, 2]); // dashed


    ctx.beginPath();

    for (let i = 0; i < timesRef.length; i++) {

      const x = timeToX(timesRef[i]);

      const y = valToY(valuesRef[i]);

      if (i === 0) ctx.moveTo(x, y);

      else ctx.lineTo(x, y);

    }

    ctx.stroke();

    ctx.restore();

  }


  // Region shading (selected analysis segment)

  const rs = clamp(regionSel.startSec, 0, tMax);

  const re = clamp(regionSel.endSec, 0, tMax);

  const x0 = timeToX(Math.min(rs, re));

  const x1 = timeToX(Math.max(rs, re));

  ctx.fillStyle = "rgba(96,165,250,0.18)";

  ctx.fillRect(x0, padT, Math.max(1, x1 - x0), plotH);


  // Handles at region boundaries

  ctx.fillStyle = "#1d4ed8";

  ctx.fillRect(x0 - 2, padT, 4, plotH);

  ctx.fillRect(x1 - 2, padT, 4, plotH);

  const ph = clamp(playheadSec, 0, tMax);

  const xPH = timeToX(ph);

  ctx.strokeStyle = "#f97316";

  ctx.lineWidth = 1.5;

  ctx.beginPath();

  ctx.moveTo(xPH, padT);

  ctx.lineTo(xPH, padT + plotH);

  ctx.stroke();

}


/**

 * Map x coordinate in canvas to time in seconds.

 */

function regionFromX(x, w) {

  const padL = 40;

  const padR = 10;

  const plotW = w - padL - padR;

  if (plotW <= 0 || !trackDurationSec) return 0;

  const norm = clamp((x - padL) / plotW, 0, 1);

  return norm * trackDurationSec;

}

  const x      = xCss * scaleX;                             // transform to canvas coords

  if (nextRegionPoint === 'start') {

    regionSel.endSec   = trackDurationSec;  // provisional full end

    nextRegionPoint    = 'end';

  } else {

    regionSel.endSec = clamp(t, 0, trackDurationSec);

      const tmp          = regionSel.startSec;

      regionSel.startSec = regionSel.endSec;

      regionSel.endSec   = tmp;

    }

    nextRegionPoint = 'start';

    updateRegionAnalysis();

  }


  drawLoudnessCurve();

});

/**

 * Compute crest factor and peak density over [t0,t1] for a buffer.

 */

function analyzeRegionWave(buffer, t0, t1) {

  if (!buffer) return null;

  const sr  = buffer.sampleRate;

  const len = buffer.length;

  const ch  = buffer.numberOfChannels;


  const start = Math.max(0, Math.floor(t0 * sr));

  const end   = Math.min(len, Math.floor(t1 * sr));

  if (end <= start + 1) return null;


  // Downmix to mono

  const mono = new Float32Array(end - start);

  for (let c = 0; c < ch; c++) {

    const d = buffer.getChannelData(c);

    for (let i = start, j = 0; i < end; i++, j++) {

      mono[j] += d[i] / ch;

    }

  }


  const N = mono.length;

  let maxAbs = 0;

  let sumSq  = 0;

  const thresholdAmp = Math.pow(10, -18 / 20); // amplitude threshold ≈ -18 dBFS

  let peakCount = 0;


  // Compute RMS and max peak

  for (let i = 0; i < N; i++) {

    const v = mono[i];

    const av = Math.abs(v);

    if (av > maxAbs) maxAbs = av;

    sumSq += v * v;

  }


  // Count local maxima above thresholdAmp

  for (let i = 1; i < N - 1; i++) {

    const v = mono[i];

    const av = Math.abs(v);

    if (av < thresholdAmp) continue;

    if (av >= Math.abs(mono[i-1]) && av >= Math.abs(mono[i+1])) {

      peakCount++;

    }

  }


  const rms = Math.sqrt(sumSq / N) || 1e-12;

  const crestDb = 20 * Math.log10((maxAbs || 1e-12) / rms);

  const maxDbFS = 20 * Math.log10(maxAbs || 1e-12);

  const rmsDbFS = 20 * Math.log10(rms);


  const duration = (end - start) / sr;

  const density  = duration > 0 ? peakCount / duration : 0;


  return {

    crestDb,

    peakDensity: density,

    maxDbFS,

    rmsDbFS

  };

}


/**

 * Estimate Zwicker loudness in sones over [t0,t1] using Bark-band levels.

 * Optional gainDb applies a virtual loudness normalization (target - integratedLUFS).

 */

function estimateZwickerSones(base, t0, t1, gainDb = 0) {

  if (!base || !base.numFrames) return NaN;

  const { numBands, numFrames, levels, frameHopSec } = base;

  const startFrame = clamp(Math.floor(t0 / frameHopSec), 0, numFrames - 1);

  const endFrame   = clamp(Math.floor(t1 / frameHopSec), 0, numFrames - 1);

  if (endFrame <= startFrame) return 0;


  let totalSones = 0;


  for (let b = 0; b < numBands; b++) {

    let sumL = 0;

    let validCount = 0;

    for (let t = startFrame; t <= endFrame; t++) {

      const L = levels[b][t]; // band level in dBFS-ish

      if (!isFinite(L)) continue;

      sumL += L;

      validCount++;

    }

    if (!validCount) continue;


    const LmeanDbFS = sumL / validCount;


    // Apply virtual loudness normalization gain in dB

    const LnormDbFS = LmeanDbFS + gainDb;


    // Rough mapping to phon (0 dBFS -> ~100 phon)

    const Lphon = LnormDbFS + 100;

    if (Lphon <= 0) continue;


    let soneBand;

    if (Lphon >= 40) {

      // >40 phon: 10 phon = 2x loudness (2^(Δphon/10))

      soneBand = Math.pow(2, (Lphon - 40) / 10);

    } else {

      // <40 phon: non-linear power law

      soneBand = Math.pow(Lphon / 40, 2.6);

    }


    if (isFinite(soneBand) && soneBand > 0) {

      totalSones += soneBand;

    }

  }


  return totalSones;

}


/**

 * Update crest/peak density/Zwicker region metrics for main + ref.

 * Uses current regionSel and platform target (for virtual normalized Zwicker).

 */

function updateRegionAnalysis() {

  const t0 = Math.max(0, regionSel.startSec);

  const t1 = Math.max(t0, regionSel.endSec);


  // Determine platform target LUFS for Zwicker normalization

  const platform = platformSelect.value;

  const targets = {

    spotify: -14,

    youtube: -14,

    apple:   -16,

    tidal:   -14

  };

  const targetLUFS = targets[platform] ?? -14;


  // ---------- MAIN TRACK ----------

  if (!decodedBuffer || t1 <= t0) {

    regionMainCrestEl.textContent   = "–";

    regionMainPeakEl.textContent    = "–";

    regionMainZwickerEl.textContent = "–";

  } else {

    const rMain = analyzeRegionWave(decodedBuffer, t0, t1);

    if (!rMain) {

      regionMainCrestEl.textContent = "–";

      regionMainPeakEl.textContent  = "–";

    } else {

      regionMainCrestEl.textContent = `${rMain.crestDb.toFixed(2)} dB`;

      regionMainPeakEl.textContent  = `${rMain.peakDensity.toFixed(2)} /s`;

    }


    // Virtual gain to simulate normalized level at target LUFS

    let gainMainDb = 0;

    if (lastAnalysis && isFinite(lastAnalysis.integratedLUFS)) {

      gainMainDb = targetLUFS - lastAnalysis.integratedLUFS;

    }

    const zMain = estimateZwickerSones(mp3LastRes, t0, t1, gainMainDb);


    if (isFinite(zMain) && zMain > 0) {

      regionMainZwickerEl.textContent = `${zMain.toFixed(2)} sones`;

    } else {

      regionMainZwickerEl.textContent = "0.00 sones";

    }

  }


  // ---------- REFERENCE TRACK ----------

  if (!decodedBufferRef || t1 <= t0) {

    regionRefCrestEl.textContent   = "–";

    regionRefPeakEl.textContent    = "–";

    regionRefZwickerEl.textContent = "–";

  } else {

    const rRef = analyzeRegionWave(decodedBufferRef, t0, t1);

    if (!rRef) {

      regionRefCrestEl.textContent = "–";

      regionRefPeakEl.textContent  = "–";

    } else {

      regionRefCrestEl.textContent = `${rRef.crestDb.toFixed(2)} dB`;

      regionRefPeakEl.textContent  = `${rRef.peakDensity.toFixed(2)} /s`;

    }


    // Virtual gain for ref based on ref integrated LUFS

    let gainRefDb = 0;

    if (lastAnalysisRef && isFinite(lastAnalysisRef.integratedLUFS)) {

      gainRefDb = targetLUFS - lastAnalysisRef.integratedLUFS;

    }

    const zRef = estimateZwickerSones(mp3LastResRef, t0, t1, gainRefDb);


    if (isFinite(zRef) && zRef > 0) {

      regionRefZwickerEl.textContent = `${zRef.toFixed(2)} sones`;

    } else {

      regionRefZwickerEl.textContent = "0.00 sones";

    }

  }

}
